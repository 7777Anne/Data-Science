# Incoming quality inspection (fictional demo)

At the start of each shift, the quality inspector verifies calibration status, checks the inspection checklist version and samples the first five units from the production lot. Measurements are recorded against the approved tolerance sheet.

When visual inspection identifies a defect, segregate the affected units, record the defect code and lot number, and alert the quality lead. Only the quality lead can approve release or rework.

All values and instructions here are illustrative, not industrial compliance guidance.
