# Precision Medicine / Population Health Dashboard — Historical Project

**Status: historical resume project, original dashboard/source not yet recovered.** No patient-level data or unverified clinical predictions are hosted.

Previously described objective: visualize disease prevalence across population groups.

## Reproducible rebuild plan
- Use permissibly licensed, **aggregated** public health data (with clear geography, coverage and sampling limitations).
- Document denominator, stratification, suppression thresholds, year, ascertainment and missingness.
- Design an interactive dashboard with filters, data-source citations, uncertainty and chart accessibility.
- Add tests for percentages, subgroup denominators, duplicate records and missing group labels.
- Explicitly avoid diagnosis, patient recommendations, demographic stereotyping or medical-device claims.

This is a research reconstruction plan, not a validated clinical tool.
